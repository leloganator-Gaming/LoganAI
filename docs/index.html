Atelier d’auto-apprentissage

LoganAI fabrique des variantes de dialogues à partir de sa base actuelle, vérifie les doublons et vous laisse les valider avant de les utiliser. Les exemples restent enregistrés dans ce navigateur.

Chargement de la base…
Limite actuelle : cette fonction crée des reformulations contrôlées, pas de nouvelles connaissances vérifiées. Elle ne modifie pas les poids du modèle ONNX et ne synchronise pas les données entre appareils.

À propos

GitHub Pages héberge l'interface et le modèle. L'inférence est réalisée localement sur votre appareil avec ONNX Runtime Web et WebAssembly.

Ce prototype utilise un petit Transformer entraîné sur un corpus pédagogique restreint. Il ne possède pas les capacités d'un assistant généraliste.
